# shadowarmy Realm

This private repository is your shadowarmy Realm: the control room of an AI software team where you, the Monarch, are the only human.

- **Place an order:** open an issue with the **Order** form, then add the `arise` label.
- **Follow it:** the issue's labels show its state, and one status comment explains what is happening, with links.
- **Merge:** pull requests appear in the target repository. Review and merge them there. Nothing merges without you.

Configuration lives in `shadowarmy.yml`, your standing rules in `rules/company.md`, and per-project notes in `projects/`.
