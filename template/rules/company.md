# Company Rules

Standing engineering rules for every agent in this Realm. Edit them to match how you work.

- Make the smallest change that fully solves the task. Do not refactor unrelated code.
- Follow the existing style, structure and tooling of each repository.
- For bug fixes, reproduce the bug first and keep the reproduction as a test when the project has tests.
- Run the project's tests, lint and build before reporting done, and report the real results.
- Never commit secrets, credentials or personal data.
- Keep dependencies to what the task needs; prefer the project's existing libraries.
